NeurIPS / Curran Associates

Integrasi retrieval hybrid (dense + sparse), mekanisme pembaruan indeks streaming tanpa re-indexing penuh, dan adaptasi untuk data relasional/operasional.

Sintesis Gap & Hubungan dengan Proyek RAG-TELE-BOT (Novelty)

  1. Real-time Dynamic Stock Synchronization: Mengatasi kelemahan RAG statis dengan arsitektur hybrid Cloudflare D1 (SQL ACID) + Cloudflare Vectorize yang tersinkronisasi otomatis saat mutasi stok terjadi.
  2. Operational Audit Trail: Menyediakan tabel stock_mutations dan halaman monitoring /monitor berotentikasi untuk melacak siapa admin yang mengubah stok dan riwayat perubahannya.
  3. Serverless Edge Deployment: Mengurangi biaya sewa GPU cloud dedicated dengan arsitektur edge serverless Cloudflare Workers AI (<1.5 detik respons).
